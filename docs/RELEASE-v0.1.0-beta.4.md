# Wayfinder v0.1.0-beta.4

新建文件夹改用 Finder 风格的直接创建流程。

- 移除命名弹窗；点击立即创建 `untitled folder`，同名自动编号。
- 空文件夹、单文件分组和多文件分组统一选中新文件夹并进入 Finder 内联重命名。
- 菜单项去掉省略号。可直接输入新名称，按 Return 确认修改。
- 在原父目录中改名后，Wayfinder 的“撤销新建文件夹”仍能恢复文件；按文件身份辨认目录，保护原路径上的替换内容。
- 未获辅助功能权限时，仍创建并选中，可手动按 Return；不会自动弹出授权或命名窗口。若用户开始其他输入，自动重命名会让出控制。

37 项核心测试通过，含自动编号、并发同名、改名后撤销及外部内容保护。最终构建在真实 Finder 中验证了空文件夹、单文件、3 文件分组的自动内联重命名，以及三种改名后的撤销与内容恢复。

自动重命名使用 Finder 的原生 Rename 命令，识别英文、简体中文和繁体中文菜单；本轮实测为英文 Finder 列表视图。其他语言可在创建后手动按 Return。

Apple Silicon（arm64），macOS 13+。仍为 ad-hoc 签名测试版，尚未 Developer ID 签名或公证；更新可能需要对当前 App 重新授权。无需关闭系统安全保护。
