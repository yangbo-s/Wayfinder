# Wayfinder v0.1.0-beta.5

剪切提示音改为五款内置原创音效，可在“权限与设置”里选择和试听，自动保存选择：轻快剪切、金属咔嚓、剪纸摩擦、柔和短划、干脆双击。

- 默认使用最早制作的“轻快剪切”，替换原来的系统 Tink 声。
- 保留原有提示音开关；关闭自动提示后，仍可主动试听。
- 音量跟随 macOS 系统音效设置；关闭“播放用户界面音效”时会静音。
- 五款音效均为原创合成，采用 MIT 许可；提供单独音效包，包含 WAV、对比试听、生成代码和许可。音频已经内置 App，无需另外安装。

## 下载与安装

- Apple Silicon Mac：下载 DMG，将 Wayfinder.app 拖到 Applications；或使用 ZIP。
- macOS 13 或更新版本；Intel 尚无经过验证的安装包。
- `Cut-Sounds.zip` 为可选的音效源文件包，`SHA256SUMS.txt` 用于校验所有下载文件。

仍为 ad-hoc 签名的测试版，尚未使用 Developer ID 公证。更新后 macOS 可能要求重新启用当前 App 的辅助功能访问；音效选择和试听本身不需要此权限。

## 验证范围

37 项核心测试和 7 项音效集成测试通过。测试覆盖五款实际 WAV 的加载、缺失/损坏资源、选择持久化、旧版静音设置保留、试听与剪切共用音效选择、关闭自动提示和播放失败处理。实际设置窗口及发布下载验证见仓库验收记录。
