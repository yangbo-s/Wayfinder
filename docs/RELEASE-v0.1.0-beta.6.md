# Wayfinder v0.1.0-beta.6

剪切音效新增九款，共十四款。全部内置 App，可在“权限与设置”中选择、试听，选择自动保存。

- 新增清脆单击、紧凑双击、机械咔嗒、利落轻重双击、分明轻重双击。
- 机械轻重双击提供 13、20、27、46 ms 四种间隔，名称中直接标明。
- 原来的五款声音、默认音效及已有选择全部保留，升级不会重置提示音开关。
- 所有声音保持原试听版本，采用 MIT 许可。单独音效包包含两组 WAV、试听文件、生成器和许可；无需单独安装即可在 App 中使用。

## 下载与安装

Apple Silicon Mac 下载 DMG，将 Wayfinder.app 拖到 Applications；也可下载 ZIP。要求 macOS 13 或更新版本，Intel 尚无经过验证的安装包。

`Cut-Sounds.zip` 为可选的音效源文件包，包含 `cut-options` 原五款与 `crisp-cut-options` 新九款。`SHA256SUMS.txt` 用于校验 DMG、App ZIP 和音效 ZIP。

仍为 ad-hoc 签名的测试版，尚未使用 Developer ID 公证。更新后 macOS 可能要求重新启用当前 App 的辅助功能访问；音效选择和试听本身不需要此权限。

## 验证范围

37 项核心测试和 8 项音效集成测试通过。验证十四份实际音频加载及缓存、旧版选择兼容、逐项保存、试听和剪切使用当前音效、关闭提示音和资源错误处理。实际设置菜单十四项齐全，App、DMG、ZIP 与音效源包均保持原音频字节。完整结果与未运行项见仓库 `docs/ACCEPTANCE.md`。
