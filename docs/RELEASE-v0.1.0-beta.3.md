# Wayfinder v0.1.0-beta.3

新增随时可用的新建文件夹操作，并将 Finder 工具栏改成真正的功能菜单。

- 右键菜单前加入小图标；终端入口统一为“在当前目录下打开终端”。
- 工具栏下箭头现在打开菜单：终端、复制路径、新建文件夹。
- 无论是否选中文件，都可新建空文件夹；支持将单个或多个所选项目放入命名的新文件夹。
- 新建前可输入名称或取消。已有项目不覆盖，保留符号链接本身，移动失败时尝试恢复原位置。
- Wayfinder 菜单栏和概览可撤销本次会话中最近一次新建/分组；这与 Finder 的 ⌘Z 独立。撤销遇到外部改动会保留现有文件并提示。

33 项核心测试通过，覆盖空/单/多文件、2000 项请求传输、名称与选择校验、链接、故障回退和安全撤销。Finder 的空目录、单项/多项分组及撤销均已实测。

Apple Silicon（arm64），macOS 13+。退出旧版后，将 DMG / ZIP 内的 Wayfinder.app 替换到 Applications。仍为 ad-hoc 签名测试版，尚未 Developer ID 签名或公证；更新可能需要对当前 App 重新授权。无需关闭系统安全保护。

已知边界：Finder 决定右键菜单插入位置；虚拟视图或跨目录所选项目没有共同的创建目录。文件分组不是跨文件原子事务；网络卷、文件提供商和只读卷尚未完整端到端验证。
