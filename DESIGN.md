# Wayfinder settings

Native macOS Operate surface. A compact system utility with a restrained slate accent, standard San Francisco typography, SF Symbols, semantic system backgrounds, native buttons, switches, pickers and focus behavior. Light and dark follow macOS automatically.

The settings window uses a 190-point navigation rail and a scrollable main pane. Page headings are 27-point semibold; controls and body 12–14 points. Overview lists the three jobs as aligned rows, followed by permission readiness and immediate actions. Terminal selection has a separate page; custom launch arguments appear only when needed. Permissions and login controls are on the third page; software updates are on the fourth page.

Direction assumption: familiar macOS inspector, low cognitive load, no ornamental onboarding or generated imagery. Functional native UI takes precedence over the generic skill's web concept gallery. Minimum content size 760×610; window can grow. Long paths wrap and are selectable. Error messages persist until dismissed; permission success is written in text as well as an icon.

Verified against the running macOS dark appearance: overview, terminal selection, and permissions/settings. Independent review inspected the permissions view and found no blocking layout defects. Sound defaults on; login remains opt-in. Light appearance and VoiceOver have not received runtime verification.

Cut sound controls use a compact native picker and an adjacent labeled speaker/试听 button below the sound toggle. The picker stays usable when automatic feedback is off, and preview is always an explicit action. Selection saves immediately without a modal. The help text explains that system sound settings also apply. Five descriptive Chinese names replace draft A–E labels in the product.

Finder menus use 16-point SF Symbols and exact action labels. The host drops template tinting during menu transport, so menu pixels resolve semantic labelColor in the extension's effective appearance. The toolbar now opens a real menu. Creation uses no NSAlert: create immediately, select the new folder, and enter native Finder inline rename. Return commits the name; retaining the default name requires no extra input. The native Rename command is matched in English, Simplified Chinese and Traditional Chinese Finder; other menu languages fall back to selection and manual Return. Menu labels omit ellipses. If existing Accessibility permission is unavailable, creation and selection still succeed; the status explains manual Return without interrupting Finder with another dialog. Full App branding and the compact folder/turn-arrow toolbar mark remain unchanged.

Software updates preserve the native Chinese settings language, system typography, semantic colors and navigation. The page shows the current version and build, a native “检查更新…” button, and the last-check time or “尚未检查更新” status. A divider separates this status area from the two native switches, “自动检查更新” and “自动安装更新”, with 24-point spacing between groups and 12-point secondary help text. Both automatic preferences default off. Automatic installation is disabled while automatic checks are off, with the prerequisite explained immediately below; enabling checks changes the explanation to background download and installation on exit, including prompts when needed and waiting for active folder operations. A pending version appears as a text-and-symbol label, and startup errors remain selectable orange text. Sparkle provides the update dialogs, feed retrieval, downloads and signature verification. The final help line explains the GitHub connection and that files, paths and system profiles are not uploaded.
