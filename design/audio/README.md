# Wayfinder 原创剪切音效

十四款音效均已内置 v0.1.0-beta.6，可在 App 的“权限与设置”中选择和试听。升级保留原选择与提示音开关。

- `cut-options/`：原五款 A–E，包括轻快剪切、金属咔嚓、剪纸摩擦、柔和短划和干脆双击。
- `crisp-cut-options/`：新九款 F–N，包括单击、轻重双击、机械咔嗒；机械双击的主触点间隔为 13、20、27、46 ms。

各目录包含单次 WAV、试听或对比文件、Python 标准库生成器、音频指标与 MIT 许可。所有声音均为原创合成，不含第三方音频采样。App 仅加载单次 WAV；这些源码和试听文件无需额外安装。
