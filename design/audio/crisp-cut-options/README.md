# Wayfinder 干脆剪切音效候选

F 至 M 八款按用户要求原样保留，包括原文件与试听文件。新增 N 机械双击，沿用 K、M 的音色与轻重比例，两声间隔为 20 ms，共九个干脆风格候选。

这些音效突出瞬间触碰与快速收尾，减少摩擦、沙沙质感。采用短接触脉冲与强衰减共振合成，不使用持续噪声层，也不使用任何第三方或系统录音采样。生成器与音频均采用附带的 MIT 许可，可随 App 打包发布。

| 编号 | 名称 | 设计 | 文件长度 |
|---|---|---|---|
| F | 清脆单击 | 一下轻脆的“嗒”，快速收尾 | 75 ms |
| G | 紧凑双击 | 一轻一重两下，间隔 26 ms | 105 ms |
| H | 机械咔嗒 | 稍有厚度的接触声，带轻微闭合感 | 85 ms |
| I | 利落轻重双击 | 第一声更轻，两声间隔 17 ms，短而紧凑 | 95 ms |
| J | 分明轻重双击 | 两声间隔 46 ms，第二声更扎实 | 125 ms |
| K | 紧凑机械双击 | 轻触后扣合，间隔 27 ms，保留 H 的闭合质感 | 110 ms |
| L | 厚实机械双击 | 轻触后较厚的扣合声，间隔 46 ms | 135 ms |
| M | 贴合机械双击 | 沿用 K 的轻重与机械质感，两声间隔缩短至 13 ms | 90 ms |
| N | 20 ms 机械双击 | 与 K、M 相同音色及轻重比例，两声间隔 20 ms | 100 ms |

- `F-*.wav` 至 `N-*.wav`：用于 App 的单次音效；双击一次触发即播放一组轻重声。
- `preview-*.wav`：对应声音重复三次，间隔 0.65 秒，方便试听短音效。
- `compare-F-G-H.wav`：按 F → G → H 播放两轮，间隔一秒。
- `compare-I-J-K-L.wav`：按 I → J → K → L 播放两轮，间隔一秒。
- `compare-M.wav`：M 播放两轮，间隔一秒。
- `compare-N.wav`：N 播放两轮，间隔一秒。
- `metrics.json`：峰值、长度以及 99% 能量结束位置；用于检查声音是否拖尾，不代替主观听感。

格式为 mono PCM16 / 48 kHz WAV，首尾采样为零，峰值保留至少 4.4 dB 余量。运行 `python3 generate.py` 可重新生成；仅使用 Python 标准库。

本目录九款音效自 v0.1.0-beta.6 起全部内置 App，与 `../cut-options` 的原五款共同提供十四个选项；资源保留试听时的原始字节。
